## 🚀 Featured Project

### Intelligent Financial Decision-Support Solution — ArabSoft

An end-to-end solution designed to transform financial ERP data into actionable insights through automated data processing, interactive reporting, predictive analytics, and artificial intelligence.

**Key components**

- ⚙️ **Automated ETL:** n8n workflows and Python microservices for processing structured and unstructured data, including Excel, CSV, JSON, PDF, and images.
- 🗄️ **Data Warehousing:** A staging database and a dimensional data warehouse built with PostgreSQL to support financial analysis.
- 📊 **Business Intelligence:** Interactive Power BI dashboards, financial KPIs, treasury monitoring, and budget analysis.
- 🤖 **Predictive Analytics:** Machine learning models for treasury forecasting, customer risk scoring, segmentation, and anomaly detection.
- 🧠 **AI Integration:** AI agents for data processing, KPI generation, intelligent reporting, and conversational assistance.
- 📄 **Automated Reporting:** PDF reports enriched with AI-generated insights.
- 🌐 **Web Portal:** A dedicated interface for accessing analytics and managing user permissions.

**Technologies:** Python · SQL · PostgreSQL · n8n · FastAPI · Power BI · Machine Learning · Generative AI

> The objective: reduce manual processing, improve data quality, automate reporting, and support better financial decisions.
